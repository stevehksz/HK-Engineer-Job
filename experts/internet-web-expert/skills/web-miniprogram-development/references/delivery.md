# 小程序预览与托管发布

静态小程序不使用云服务，也可以在 WorkBuddy 内完成预览和发布。

交付与发布分两段：

1. 开发完成并通过基础校验后，调用 `sites` 创建或复用小程序应用。
2. 该步骤只完成 application registration / preview：返回一张 `.genie` 应用卡，`deployed: false`，表示当前未发布。
3. 用户点击小程序应用卡片打开预览。
4. 如需发布，用户在预览右上角点击「分享 / Share」。
5. 用户可选择以下一种方式继续：
   - **试用小程序**：扫码创建，适合体验和临时分享。
   - **绑定已有小程序**：扫码授权已有账号，之后可发布体验版或提交正式版审核。

不要说小程序不能发布，也不要要求用户通过微信开发者工具手工上传。

## 发布相关的界面知识

### 入口与面板

- 预览面板右上角有「分享」图标，位于刷新和「…」的左边。点击后打开「分享」面板。
- 「分享」面板展示当前小程序的绑定状态，以及按版本分行的发布状态：试用版、体验版、正式版。
- 面板里可以选择试用小程序或绑定已有小程序，并执行发布。
- 面板里有「更新」按钮，用于把修改后的代码重新发布；改完代码不会自动同步到线上。
- 面板里有「解绑」按钮，用于更换所绑定的小程序。

### 小程序码

- 发布成功后，对应版本那一行显示「已发布」，行的最右侧是二维码图标。
- 鼠标悬停在二维码图标上，会弹出该版本的小程序码，下方有「复制」和「下载」；用微信扫码即可打开。
- 未发布的版本，二维码图标是灰色不可点的，悬停提示「请发布后查看」。
- 已发布但取码失败时，弹层提示小程序码暂不可用，可以重试。
- 另一个取码位置：「设置 > 数据管理 > 应用」里，已发布的小程序那一行也有二维码入口，只能下载，不能复制。未发布的应用没有这个入口。
- 预览面板里的模拟手机不是扫码入口。

### 试用小程序

- 试用小程序有有效期，面板上会显示「请在某个日期前发布使用」，以面板显示的日期为准。
- 面板上显示的有效期、审核次数、备案、隐私指引等信息会随微信规则变化，回答时引用面板或发布返回的提示，不要凭记忆给出具体数字。

### 回答原则

- 只取与当前问题相关的事实，界面信息以上述为准，不通过联网搜索确认。
- 操作类内容以面板上的实际步骤为单位：分享图标 → 分享面板 → 选择方式 → 发布 → 对应版本行 → 悬停二维码图标。
- 位置类内容说明所在位置和用途。
- 绑定或发布状态不明时，按各状态下的差异说明，不假设已发布。
